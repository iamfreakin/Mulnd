소리공방 · 짧은 게임 효과음 편집기

실행과 개발
- 압축본에서는 실행 폴더의 SoriLab.exe를 실행하고, 프로젝트 열기에서 예제 폴더의 다중트랙_검수.sorilab을 선택하세요.
- 검수용 실행 파일: outputs/실행/SoriLab.exe
- 예제 프로젝트: outputs/예제/다중트랙_검수.sorilab
- SoriLab.sln을 Rider에서 열고 SoriLab.App을 실행합니다.
- .NET 8 Windows 데스크톱 런타임이 필요합니다.
- 빌드: dotnet build SoriLab.sln -c Release
- 검사: dotnet run --project SoriLab.Checks -c Release -- work/checks

현재 기능
- 여러 WAV를 트랙으로 추가하고 배치 위치를 조정하여 겹쳐 재생합니다.
- 새 트랙은 WAV를 새 행으로 추가합니다. 클립 추가는 선택 트랙의 편집 커서 위치에 WAV를 넣습니다.
- 같은 트랙에 여러 클립을 놓을 수 있습니다. 클립은 소리 조각이고, 트랙은 클립을 담는 가로줄입니다.
- 다른 트랙의 소리는 함께 재생합니다. 같은 트랙에서 겹치면 앞에 보이는 클립만 재생합니다.
- 클립을 좌우 또는 다른 트랙으로 드래그해 옮깁니다. 아래 빈 행에 놓으면 새 트랙이 됩니다.
- 클립 복제는 같은 트랙의 원래 클립 끝에 붙입니다.
- 클립이나 눈금을 클릭해 편집 커서를 옮기고, 분할 버튼 또는 S로 나눕니다.
- 분할은 현재 속도·역재생·음량·페이드를 소리에 반영한 뒤 나눕니다. 원본 파일은 바뀌지 않습니다.
- 분할 이전의 효과 설정으로 돌아가려면 실행 취소하세요. 분할 후에도 새 효과를 적용할 수 있습니다.
- 시간축을 1~8배 확대하고 가로 스크롤로 이동할 수 있습니다.
- 원본 구간 자르기, 음량, 페이드 인·아웃, 재생 속도, 역재생을 적용합니다.
- 재생 속도를 바꾸면 소리 길이와 음높이가 함께 바뀝니다.
- 트랙 음소거·단독 듣기, 전체 음량, 실행 취소·다시 실행을 지원합니다.
- 소리 생성 창에서 사인파·삼각파·사각파·노이즈를 만들 수 있습니다.
- 소리 생성의 페이드를 0ms로 지정하면 클릭 잡음 방지를 위해 2ms를 적용합니다.
- .sorilab 프로젝트는 원본 소리와 편집 설정을 함께 보관합니다.
- WAV 내보내기는 들리는 트랙을 48kHz·스테레오·16비트 파일로 합칩니다.
- 선택 재생과 음량·페이드 없이 비교는 미리 듣기에만 적용합니다.
- 원본 WAV는 덮어쓰지 않습니다. 프로젝트 저장과 WAV 내보내기는 별도입니다.

화면 구성
- Studio One의 작업 화면을 참고해 상단 메뉴·편집 도구, 왼쪽 상세 설정, 중앙 배치, 오른쪽 탐색기, 하단 믹서·편집기로 구성했습니다.
- 믹서에는 실제 트랙이 표시됩니다. 트랙 선택과 음소거·단독 듣기는 연결되어 있습니다.
- 하단의 편집기/믹서 버튼으로 두 화면을 전환하고, 탐색기는 접었다 펼칠 수 있습니다.
- 탐색기의 소스 목록을 선택하면 해당 소리를 쓰는 클립이 선택됩니다.
- 효과·악기·루프, 플러그인 삽입·보내기, 트랙 팬·페이더, 녹음·박자 관련 영역은 준비 중인 화면 틀입니다.
- 준비 중인 기능은 소리 처리에 적용되지 않습니다. 출력 최대 음량은 정적 분석 결과이며 실시간 미터가 아닙니다.

사용 범위
- 30초 이내 게임 효과음 제작이 주 용도이며 전체 배치는 120초까지입니다.
- 최대 32트랙·128클립·서로 다른 원본 32개, 원본 합계 3,200만 샘플까지 지원합니다.
- WAV 입력만 지원합니다. MP3·OGG 입력, 녹음, MIDI, VST는 포함하지 않습니다.
- 속도와 독립적인 음높이 조절은 포함하지 않습니다.
- 반복 재생은 미디어 재생기를 다시 시작하므로 무간격 루프를 보장하지 않습니다.
- 프로젝트의 실행 취소 이력은 앱을 닫으면 초기화됩니다.

단축키
- Ctrl+S: 프로젝트 저장
- Ctrl+Z / Ctrl+Y: 실행 취소 / 다시 실행
- Ctrl+D: 선택 클립 복제 / Delete: 선택 클립 제거
- S: 편집 커서에서 클립 분할
- F2: 편집기 / F3: 믹서 / F5: 탐색기
- Space: 재생 / 일시정지 (텍스트 입력 중 제외)

검증
- 오디오·조합·생성·프로젝트·다중 클립 자동 검사 134개 통과.
- 앱에서 재생·정지·실행 취소·저장·재열기 및 오류 후 작업 보존 검증.
- 30초 스테레오 파일과 1180×800 최소 창 크기를 사용한 앱 처리 함수·화면 검증.
- 운영체제의 실제 마우스·키보드 조작 자동화와 주관적인 청음 검수는 포함하지 않았습니다.
